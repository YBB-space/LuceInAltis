센서에서 지상국까지. ALTIS는 비행 데이터를 계측하고 기록하며, 통신·점화·전원 제어와 운영 소프트웨어를 하나의 시스템으로 직접 설계합니다.

01 / System Overview

비행의 모든 신호를
하나의 흐름으로

ALTIS의 에비오닉스는 보드 한 장으로 끝나지 않습니다. 센서 계측, 실시간 상태 판단, 비행 기록, 무선 통신, 지상국 시각화가 하나의 데이터 규격으로 이어집니다. 하드웨어와 소프트웨어를 함께 설계해 지연과 변환 손실을 줄이고, 비행 전 과정의 데이터를 일관되게 유지합니다.

INPUT / 01 Flight Sensors

IMU, 기압·고도, 위치와 전원 상태를 비행 중 연속 계측합니다.

COMPUTE / 02 FLASH6

상태 판단, 이벤트 시퀀스, 파이로·서보 제어와 비행 기록을 수행합니다.

LINK / 03 A.I LINK

기체 간 중계와 지상국 링크를 관리하고 텔레메트리와 명령을 전달합니다.

GROUND / 04 Mission Software

HUD, 자세·궤적, 지도, 이벤트와 저장 기록을 하나의 화면에서 운영합니다.

02 / Hardware + Software

같이 설계하고,
같이 검증합니다

펌웨어와 운영 소프트웨어는 동일한 이벤트·텔레메트리 정의를 공유합니다. 보드에서 생성된 데이터가 화면과 보고서까지 같은 의미로 유지되도록 인터페이스를 설계합니다.

Flight Hardware

FLASH6
Flight Computer

비행 센서, 통신, 저장장치와 안전 출력부를 통합한 ALTIS의 비행 컴퓨터입니다. 실시간 루프를 방해하지 않도록 계측·기록·통신 작업을 분리하고, 비행 이벤트를 결정론적으로 처리합니다.

  • AcquisitionIMU·기압·고도·위치·전원 텔레메트리 계측
  • Control파이로 채널, 서보, 안전 모드와 비행 시퀀스 관리
  • Storage온보드 SPI Flash 비행 기록 및 지상국 다운로드
  • Runtime통신과 기록이 센서 루프를 막지 않는 비동기 처리 구조
Mission Software

FLASH6
Ground Console

발사 전 점검부터 비행 중 모니터링, 회수 후 데이터 분석까지 이어지는 지상국 소프트웨어입니다. 실시간 표시와 제어 명령을 분리해 반응성을 확보하고, 저장 기록과 보고서를 같은 비행 데이터로 생성합니다.

  • Telemetry고도·속도·가속도 차트와 단계별 상태 모니터링
  • AttitudeIMU 기반 3D 자세 프리뷰, 궤적과 지도 시각화
  • OperationsARM, 안전 모드, 점화·서보 제어와 이벤트 알림
  • Data비행 기록 다운로드, 재생, 차트와 보고서 내보내기

03 / Intelligent Telemetry

A.I LINK

비행 단계와 링크 상태에 따라 데이터를 전달하는 ALTIS의 통신 계층입니다. 2단은 1단 중계를 우선 사용하고, 중계가 끊기면 지상국 직통 경로로 전환할 수 있도록 설계합니다. 지상국은 어느 경로로 들어온 데이터든 같은 텔레메트리로 처리합니다.

04 / Flight Capabilities

발사 전부터
비행 후까지

단순한 실시간 화면을 넘어, 준비·비행·회수·분석의 전 과정을 하나의 시스템에서 연결합니다.

01 / PRE-FLIGHT

상태 점검

센서, 저장공간, 통신률, 전원과 안전 상태를 발사 전에 한 화면에서 확인합니다.

02 / REALTIME

비행 텔레메트리

단계별 고도·속도·가속도와 자세, 이벤트를 지연을 줄인 실시간 스트림으로 표시합니다.

03 / CONTROL

안전 제어

ARM과 안전 모드, 점화·서보 명령을 상태 확인과 함께 수행해 오동작 가능성을 낮춥니다.

04 / RECORD

온보드 기록

무선 링크와 별개로 비행 데이터를 플래시에 보존하여 통신 음영 구간의 데이터도 남깁니다.

05 / REPLAY

비행 재생

기록된 센서·이벤트를 시간축에 맞춰 다시 재생해 비행 상태와 시퀀스를 검토합니다.

06 / REPORT

데이터 분석

고도·가속도·궤적 차트와 주요 이벤트를 보고서 형식으로 정리해 다음 설계에 반영합니다.

05 / Flight Computer Mockup

비행 컴퓨터 하우징과 전자 시스템 배치를 3D 목업으로 확인합니다. 회로와 고정 구조, 커넥터 접근성, 조립성을 함께 검토하며 실제 비행 환경에 맞춰 반복 개선합니다.
