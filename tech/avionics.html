ALTIS / AVIONICS

AVIONICS

전자팀은 비행 컴퓨터와 지상국 프로그램을 직접 설계하고 제작합니다. 기체의 상태를 기록하고 지상으로 보내며, 필요한 비행 장치를 제어합니다.

Circuit Firmware Telemetry Ground Station

01 / System Overview

기체에서 지상국까지

센서에서 읽은 값은 비행 컴퓨터에 저장되고 무선 통신으로 지상국에 전달됩니다. 전자팀은 이 과정에 필요한 회로, 펌웨어, 통신, 지상국 화면을 함께 만듭니다.

INPUT / 01 Flight Sensors

IMU와 기압 센서 등에서 기체의 상태를 읽습니다.

COMPUTE / 02 AI3

센서 값을 기록하고 사출 장치와 점화 회로를 제어합니다.

LINK / 03 Telemetry

기체의 데이터를 무선으로 지상국에 전달합니다.

GROUND / 04 FLASH6

발사 전 상태와 비행 데이터를 한 화면에서 확인합니다.

02 / Hardware & Ground Station

AI3와 FLASH6

AI3는 로켓에 탑재되는 비행 컴퓨터이고, FLASH6는 지상에서 비행 상태를 확인하는 프로그램입니다.

Flight Hardware

AI3
Flight Computer

AI3는 센서 계측, 데이터 저장, 무선 통신과 사출 장치 제어를 담당합니다. 회로 설계부터 PCB 조립과 펌웨어 시험까지 전자팀에서 진행합니다.

  • SensorIMU와 기압 센서 데이터 수집
  • Control점화·사출 채널과 서보 제어
  • Storage비행 데이터 자체 저장
  • Link지상국 텔레메트리 송수신
Ground Station

FLASH6
Ground Console

FLASH6는 발사 전에 연결 상태를 확인하고 비행 중에는 고도, 속도, 위치와 기체 상태를 표시합니다. 비행이 끝난 뒤에는 저장된 기록을 다시 확인할 수 있습니다.

  • Pre-flight센서, 통신, 저장 공간 상태 확인
  • Flight고도·속도·위치와 이벤트 표시
  • Control안전 상태 확인과 제어 명령 전송
  • Review저장 데이터 확인과 비행 기록 검토

03 / What We Do

전자팀이 하는 일

회로 설계부터 비행 후 데이터 정리까지 전자 시스템에 필요한 작업을 팀 안에서 직접 진행합니다.

01 / HARDWARE

회로 설계

전원, 센서, 통신과 제어 회로를 설계하고 PCB를 제작합니다.

02 / FIRMWARE

펌웨어

센서 값을 읽고 저장하며 비행 장치를 제어하는 코드를 작성합니다.

03 / TELEMETRY

통신

기체와 지상국 사이에서 데이터를 안정적으로 주고받도록 시험합니다.

04 / GROUND STATION

지상국

발사 전 점검, 실시간 표시와 비행 기록 확인에 필요한 화면을 만듭니다.
